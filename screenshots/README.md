# Investigation Evidence

This folder contains screenshots from the Windows logon event investigation performed using PowerShell and Splunk Cloud.

| Screenshot | Description |
|---|---|
| `01-event-counts.png` | Counts of successful and failed logon events |
| `02-failed-logon-analysis.png` | Failed logon details and authentication failure status |
| `03-successful-logons.png` | Successful logons and associated process details |
| `04-windows-logon-timeline.png` | Chronological reconstruction using original event timestamps |

Screenshots support the findings documented in [`../report/incident_report.md`](../report/incident_report.md).

The sample contains only four events and does not independently establish malicious activity.
